# Distressed Credit Signals site

This directory contains the static Next.js research site. Pages read committed JSON and figure assets from `public/` at build time. They do not depend on a running API server.

## Static inputs

- `public/data/` holds derived research artifacts and `SOURCES.json`, the source and licensing registry.
- `public/brand/`, `public/marks/` and `public/figures/` are generated by `python -m scripts.assets` from the repository root.
- `app/` contains the six public research modules: Model, Mispricing, Measurement, Discrimination, Cases and Data.

Do not edit generated assets by hand. Update the source data or generator, regenerate, and then run the root verification command.

## Development

Install dependencies and start the site:

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Use `npm run lint` for static checks and `npm run build` for a production build.

From the repository root, `python -m scripts.verify` runs asset, figure, frontend and Python checks in the same order used by continuous integration.

## Publication rule

Only completed research modules are public. A route stays unpublished until its data, method, limitations and testable claims are complete. Do not add placeholder pages or unfinished-result copy to navigation or homepage cards.
